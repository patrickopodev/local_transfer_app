    required this.address,
    required this.available,
  });
}

Then the UI simply displays it.

  static const primary = Color(...);

And:

class AppRadius {

31. Transfer state

Create something like:

enum TransferStatus {
  idle,
  connecting,
  transferring,
  completed,
  failed,
  cancelled,
}

Then:

class TransferState {
  final TransferStatus status;
  final double progress;
  final int bytesTransferred;
  final int totalBytes;
  final double speed;
  final Duration remaining;
}

Now the UI can automatically update:

72%
1.4 GB / 2.0 GB
28.4 MB/s
21 sec

instead of having those values hardcoded.

32. Important: separate frontend from networking

Don't put networking code inside your widgets.

Bad:

HomeScreen()
  → discovers devices
  → opens sockets
  → transfers files
  → calculates speed
  → displays UI

Better:

UI
 ↓
TransferController
 ↓
TransferService
 ↓
Network

For example:

NearbyDeviceCard
       ↓
TransferController
       ↓
DiscoveryService

And:

TransferScreen
       ↓
TransferController
       ↓
TransferService
       ↓
Socket/HTTP/WebSocket/etc.

This will make your frontend much easier to maintain.

Home
   ↓
Send Files
   ↓
Select Device
   ↓
Transfer
   ↓
